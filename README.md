Propósito do projeto:
Fui instruída para criar um sistema digital de controle de estoque para no futuro substituir o método manual, afinal por fazer parte da equipe de desenvolvimento da "Logística Integrada Ltda.",
que é uma empresa de gerenciamento de armazenamento de peças que com o método manual, que vem gerando falhas, causando prejuízos e dificuldades para localizar produtos, com falta de um histórico confiável de modificações.
Sua função é justamente evitar erros e falhas que possam comprometer a empresa pois com um novo sistema digital todas as informações podem ser alteradas rapidamente sem risco de erros!
